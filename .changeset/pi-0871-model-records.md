Adds support for GPT-6 Sol, GPT-6 Luna, and Claude Opus 5.5. Flue now uses Pi 0.87.1, so you can pass these models to `useModel()` without extra configuration. The model list at `https://flueframework.com/models.json` also includes them now. There are no public API changes.
